## Agola: CI/CD Redefined

[Agola](https://agola.io/) is an open-source CI/CD tool designed by Sorint.lab aiming to redefine the continuous integration and delivery experience with an emphasis on containerized, reproducible, and restartable runs. With a focus on providing advanced workflows (like matrix builds, fan-in, and fan-out) that work seamlessly across any programming language or environment, it places a high value on a Git-based workflow where run definitions are stored alongside your code.

**Key Features & Capabilities:**
- **Containerized & Reproducible Runs:** Every task executes within a container (e.g., Docker, Kubernetes), which guarantees consistency between runs and environments.
- **Restartable Runs:** A robust workflow capability allowing you to restart runs from scratch, or more efficiently, from the specific point of failure.
- **User Direct Runs:** This feature empowers developers to run their testing and deployment workflows locally on the Agola server with a single command. It effectively mimics the CI environment without requiring powerful local hardware.
- **Multi-Git Integration:** You can simultaneously connect and integrate repositories from GitHub, GitLab, and Gitea within a single Agola installation.
- **Testable Runs:** By keeping the core run definitions but substituting variables or secrets, you can test securely against various environments.

Unlike some CI/CD tools that use extended YAML for templating, Agola natively supports real templating languages like Jsonnet, making complex run generation much cleaner. It also ensures "at most once execution" by design, avoiding concurrent deployment issues that can plague production environments.

The latest release ([v0.11.0](https://github.com/agola-io/agola/releases/tag/v0.11.0) on 2024-09-25) brought updates to Go 1.25 and streamlined the gateway configurations. If you want to dive deeper into how Agola can orchestrate complex, highly available deployments via bare metal or Kubernetes, check out the [Agola Documentation](https://agola.io/doc/) and their [GitHub Repository](https://github.com/agola-io/agola).
