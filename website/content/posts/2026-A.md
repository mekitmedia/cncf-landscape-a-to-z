# Exploring Landscape Tools starting with A

In this post, we'll explore tools starting with A from the landscape.

## Agent Evaluation

[Agent Evaluation](https://awslabs.github.io/agent-evaluation/) is a generative AI-powered framework for testing virtual agents. While it is **not a CNCF project**, it is a relevant tool in the broader cloud-native and AI ecosystem. It acts as an LLM evaluator to orchestrate multi-turn conversations with your own agent target, critiquing and evaluating responses to ensure they behave as expected before going to production.

**Key Features:**
* **Built-in Integration:** Works seamlessly with Amazon Bedrock, Amazon Q Business, and Amazon SageMaker.
* **Multi-turn conversations:** Orchestrates concurrent, multi-turn testing sequences.
* **Custom Hooks:** Define hooks to perform extra validation like integration testing.
* **CI/CD Ready:** It can be integrated into pipelines to automate the time to delivery and guarantee stability.

**Community Perspectives:**
Testing AI agents is an active area of discussion in the community. Projects like [AWS-bench](https://github.com/aws-bench/aws-bench) highlight the growing need to benchmark and evaluate AI coding agents on real-world tasks, a challenge that frameworks like Agent Evaluation aim to address for conversational targets. You can find related community discussions on platforms like [Hacker News](https://news.ycombinator.com/item?id=49570089).

To learn more about the project, verify its [latest release v0.4.1 (2025-03-31)](https://github.com/awslabs/agent-evaluation/releases/tag/v0.4.1), or get started building custom targets, you can explore their [official documentation](https://awslabs.github.io/agent-evaluation/) and the [GitHub repository](https://github.com/awslabs/agent-evaluation).
