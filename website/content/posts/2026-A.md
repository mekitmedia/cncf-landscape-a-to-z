## Apache AGE

[Apache AGE](https://age.apache.org/) is a PostgreSQL Graph database extension that leverages graph data structures to analyze and use relationships and patterns in data. It effectively adds graph data processing and analytics capabilities to relational databases.

### Key Features
* Provides graph database functionality as a native PostgreSQL extension.
* Read and write graph data in nodes and edges within an existing relational database.
* Uses its own set of SQL extensions, similar to Cypher, while allowing native SQL queries.

### Getting Started
AGE stands for "A Graph Extension". To get started, you can install it as a PostgreSQL extension and begin modeling data as nodes and edges by following their [setup tutorial](https://age.apache.org/age-manual/master/intro/setup.html).
