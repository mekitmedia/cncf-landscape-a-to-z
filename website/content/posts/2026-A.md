## Apache Avro

[Apache Avro](https://avro.apache.org/) is a fast data serialization system that provides rich data structures, a compact, binary data format, and simple integration with dynamic languages.

Avro is a popular choice for streaming data pipelines, commonly integrating with systems like Apache Hadoop and Apache Kafka. Because Avro relies on schemas that are always present when data is read, it allows data to be written with no per-value overheads, resulting in small file sizes and fast serialization.

**Key Features:**
*   Rich data structures defined using JSON.
*   Compact, fast, binary data format.
*   Container file format for storing persistent data.
*   Remote procedure call (RPC).
*   Dynamic language integration with no code generation required to read or write data files.

**Getting Started:**
To get started, you can define your schema in JSON format, and then dynamically serialize or deserialize your data using one of the many supported language SDKs. For detailed information, consult the [official documentation](https://avro.apache.org/docs/).

**Recent Updates:**
The [release-1.12.2](https://github.com/apache/avro/releases/tag/release-1.12.2) (August 23, 2026) introduced hardening against malformed and adversarial input across the Java and Python SDKs, along with security fixes for C#, C++, and JavaScript.
