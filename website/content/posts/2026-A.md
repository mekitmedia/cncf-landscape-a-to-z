## Autogen

[Autogen](https://microsoft.github.io/autogen/) is a programming framework developed by Microsoft for building agentic AI. It enables the creation of applications using multiple agents that can converse with each other to solve tasks.

**Key Features:**
- Multi-agent conversations
- Customizable and conversable agents
- Code execution capability
- Seamless integration with human participation

**Recent Updates:**
The latest release, `python-v0.7.5` (2025-09-30), includes bug fixes for loading streaming Bedrock responses, linear memory support in RedisMemory, and thinking mode support for the Anthropic client. Check out the [release notes](https://github.com/microsoft/autogen/releases/tag/python-v0.7.5) for more details.

**Community Perspectives:**
AutoGen is highly regarded and often compared to other frameworks like CAMEL and BabyAGI. Discussions on platforms like Hacker News highlight its distinct code execution capability as a standout feature. With over 60,000 stars on its [GitHub repository](https://github.com/microsoft/autogen), it has seen significant adoption in the community.

**Getting Started:**
You can quickly install Autogen via pip (`pip install autogenstudio` or `pip install pyautogen`). For examples on defining agents and orchestrating conversations, refer to the [official documentation](https://microsoft.github.io/autogen/).
