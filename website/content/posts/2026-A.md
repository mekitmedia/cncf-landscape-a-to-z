Welcome to our exploration of the CNCF landscape, starting with the letter A! In this post, we are highlighting **Autogen**, a powerful tool for building AI agents.

### Autogen

[Autogen](https://microsoft.github.io/autogen/) is an open-source programming framework for building AI agents and facilitating cooperation among multiple agents to solve tasks. Developed by Microsoft Research, Autogen has gained immense popularity for providing a simple yet powerful abstraction for multi-agent LLM systems.

**Key Features:**
- Multi-agent conversation framework for orchestrating complex workflows.
- Customizable and conversable agents that can integrate with LLMs, tools, and human inputs.
- Seamless integration with human participation, allowing human-in-the-loop workflows.

**Recent Updates:**
The latest release, `python-v0.7.5` (released on 2025-09-30), includes improvements to reasoning effort parameters for OpenAI models, Redis caching support, and various bug fixes for streaming and thinking modes. You can find the release notes [here](https://github.com/microsoft/autogen/releases/tag/python-v0.7.5).

**Use Cases:**
Autogen is ideal for building complex AI agent applications, multi-agent workflows, code generation and execution, and cooperative problem solving with LLMs. It is widely used by developers looking to build sophisticated agentic systems.

**Community Opinions:**
Autogen has sparked numerous discussions within the developer community. It has been highlighted on Hacker News as a key enabler of next-gen large language model applications (see [discussion](https://news.ycombinator.com/item?id=37926741)) and reviewed in detail by e2b.dev as a robust guide to code execution by LLMs (read [here](https://e2b.dev/blog/microsoft-s-autogen)).

**Get Started:**
To get started with Autogen, you can install the library via `pip install pyautogen`. Check out the [official documentation](https://microsoft.github.io/autogen/docs/Getting-Started) for a quick start guide and start by defining a `UserProxyAgent` and an `AssistantAgent` to initiate a conversation.

Explore Autogen and see how it can enhance your AI workflows. Happy building!
