## Agola
Agola is an open-source CI/CD platform designed with an advanced architecture offering reproducible, containerized workflows (Runs). It supports a git-based workflow, integrates with multiple major git repositories (GitHub, GitLab, Gitea), and is built to be distributed, highly available, and capable of running everywhere, including Kubernetes, Docker, IaaS, or bare metal.

**Key Features:**
* Containerized, reproducible, and restartable Runs execution environment.
* Advanced workflows support including matrix builds, fan-in, fan-out, and multi-architecture.
* Seamless integration with GitHub, GitLab, Gitea, and custom Git repositories.
* Multiple execution platforms supported (Kubernetes, Docker, etc.).
* Testable runs with dynamic variable evaluation based on rules, without changing definition files.
* Direct user runs from a local git repository onto a remote Agola server with a single command.

**Recent Updates:**
The latest release is v0.11.0. For details on recent updates, check the GitHub releases page.

**Use Cases:**
Ideal for software development teams needing a flexible, robust, and highly available CI/CD system that integrates deeply with their Git workflows and runs reproducibly on local docker engines or distributed Kubernetes clusters.

**Get Started:**
To get started, visit the [official documentation](https://agola.io/doc/) and try running it standalone or deploying to Kubernetes. You can also explore the source code on [GitHub](https://github.com/agola-io/agola).

**Related Tools:** Argo, Jenkins, GitLab CI, Tekton.
