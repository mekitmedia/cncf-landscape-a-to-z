## AutoMQ

[AutoMQ](https://www.automq.com) is a cloud-native, diskless Kafka alternative built on object storage like S3. Designed to reduce costs while maintaining high performance, it offers an elastic architecture for the cloud era.

AutoMQ leverages a Shared Storage architecture, contrasting with Apache Kafka's traditional Shared Nothing approach. By offloading storage to S3, it achieves a stateless and diskless broker design. This allows for instant elasticity, multi-AZ availability, and eliminates cross-AZ fees, all while maintaining 100% compatibility with the Apache Kafka protocol. According to [AWS Storage Blog](https://aws.amazon.com/blogs/storage/achieving-sub-10ms-latency-and-94-cost-savings-with-diskless-kafka-using-automq-and-amazon-fsx-for-netapp-ontap/) and the [AutoMQ engineering team](https://www.automq.com/blog/how-automq-saves-90-of-kafkax27s-cross-az-traffic-costs), this architecture can significantly reduce storage and cross-AZ traffic costs compared to traditional deployments.

The project recently released [version 1.7.4](https://github.com/AutoMQ/automq/releases/tag/1.7.4), which introduced support for direct local writes in zerozone and other key improvements.

**Key Features:**
* Shared Storage architecture utilizing object storage like S3
* Stateless and diskless design for instant elasticity
* Zero cross-AZ fees and multi-AZ availability
* 100% compatibility with Apache Kafka protocol
