Welcome to the X edition of our CNCF landscape journey! In this post, we explore the tools and technologies that begin with the letter X.

## XGBoost

XGBoost is an optimized distributed gradient boosting library for machine learning.

**Key Features:**
* Parallel tree boosting (GBDT, GBM)
* Distributed environment support (Hadoop, SGE, MPI)
* Supports billions of examples
* Provides Python, R, JVM, Ruby, Swift, Julia, C, and C++ interfaces

**Use Cases:**
Solving data science problems in a fast and accurate way using Gradient Boosting.

## XTDB

XTDB is an open source, bitemporal database that provides universal history tracking with a complete audit trail.

**Key Features:**
* Immutable object storage with Log-Structured Merge (LSM) Tree design
* Postgres-compatible SERIALIZABLE SQL transactions
* Fine-grained interval versioning with Apache Arrow
* Native Debezium ingestion for Change Data Integration

**Use Cases:**
Auditable reporting for Change Data Integration, Virtual Power Plant orchestration, and KYC compliance.
