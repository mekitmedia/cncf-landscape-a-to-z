Ceph is a distributed object, block, and file storage platform.

### Key Features
- Distributed storage system
- Unified storage service with object, block, and file interfaces from a single cluster
- Built from commodity hardware components

### Use Cases
Transform storage infrastructure and provide unified storage service

### Recent Updates
v20.2.5 Tentacle released (recent news on ceph.io)

### Get Started
Clone the ceph/ceph repository and build using cmake and ninja, or use container build tools.
