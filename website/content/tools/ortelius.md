## Overview

Ortelius is a platform that helps security teams manage and track open source vulnerabilities. It ingests Software Bill of Materials (SBOM) at build time, continuously matches deployed components against OSV, and tracks CVE remediation across all environments.

## Key Features

- Ingests Software Bill of Materials (SBOM) at build time
- Matches deployed components against the OSV vulnerability database every 15 minutes
- Tracks every CVE from introduction to remediation
- Measures remediation SLA targets
