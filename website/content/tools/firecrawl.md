## Overview

Firecrawl is an API designed to help AI agents search, scrape, and interact with the web at scale, converting web content into clean data forms like markdown, JSON, or screenshots.



## Key Features


- Search: Find information across the web

- Scrape: Clean data from any page

- Interact: Click, navigate, and operate pages

- Agent: Autonomous data gathering

- Map: Discover all URLs on a website instantly

- Batch Scrape: Scrape multiple URLs at once




## Use Cases

Extracting training data for AI models, building autonomous AI agents that require web interaction, and performing automated web scraping at scale.



{{< callout title="Getting Started" type="code" >}}
```bash
Install via npm (`npm install firecrawl`) or pip (`pip install firecrawl`), instantiate the client with an API key, and call `app.scrape('firecrawl.dev')` or `app.agent(prompt='...')`.
```
