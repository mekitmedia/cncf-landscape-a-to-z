## Overview

Drasi provides real-time event tracking and automated responses without moving data to a central lake or continuously querying sources.

## Key Features

- Track system logs and change feeds for specific events
- Continuously evaluate incoming data changes using Continuous Queries written in Cypher Query Language
- Automatically initiate context-aware Reactions based on query updates
- Provide real-time actionable insights without copying data to a central data lake

## Use Cases

Automating responses to system events, such as matching ready orders with available delivery drivers and sending real-time notifications.
