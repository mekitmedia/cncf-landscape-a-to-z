## Overview

M3 is a distributed time series database (TSDB) and query engine, providing a metrics platform with a Prometheus sidecar and Graphite compatibility.



## Key Features


- Distributed TSDB and Query Engine

- Prometheus Sidecar integration

- Metrics Aggregator

- Graphite storage and query engine compatibility




## Use Cases

Storing and querying large volumes of time series metrics, operating as a Prometheus sidecar for long-term storage, aggregating metrics for distributed applications, and serving as a backend for Graphite-compatible platforms.
