## Overview

Quarkus is a Cloud Native, (Linux) Container First framework for writing Java applications tailored for Kubernetes and cloud environments.



## Key Features


- Container First: Minimal footprint Java applications optimal for running in containers.

- Cloud Native: Embraces 12 factor architecture in environments like Kubernetes.

- Versatile: Designed to scale from the smallest microservice to the largest monolith.

- Fast startup: Shifts work to build time, resulting in incredibly fast startup times.

- JVM and native: Provides JVM execution for high throughput or native execution for constrained environments.

- Unify imperative and reactive: Brings non-blocking and imperative development styles under one programming model.

- Standards-based: Based on popular standards and frameworks like RESTEasy, Hibernate ORM, Netty, Vert.x, and MicroProfile.

- Developer Joy: Delivers a development-centric experience with rapid live reload and tooling.




## Use Cases

Building highly efficient, minimal-footprint microservices, serverless functions, and cloud-native Java applications running in Kubernetes.
