## Overview

Mule is a lightweight integration platform that allows you to connect anything anywhere by intelligently managing message-routing, data mapping, orchestration, reliability, security and scalability between nodes.



## Key Features


- Event Driven Architecture (EDA) responding to messages initiated by external resources

- Mule transformers convert message payload data to a format that another application can understand

- Uses components to conduct backend processes for specific business logic

- Catalog of building blocks includes the most commonly used Enterprise Integration Patterns




## Use Cases

Connecting systems, services, APIs and devices intelligently without creating point-to-point integrations.
