## Overview

Authing is a developer-centric, API-First, full-scene (B2C/B2B/B2E) identity cloud and IAM (Identity and Access Management) solution.



## Key Features


- Multi-factor authentication (MFA)

- API-First design

- Universal Directory (Guard) and embeddable login form

- Custom Database Connections

- SSO (Single Sign-On)




## Use Cases

Providing unified login experiences for SaaS platforms, managing enterprise workforce access, and securing digital identities.



{{< callout title="Getting Started" type="code" >}}
```bash
To get started, developers can use the SDK or Authing Guard universal component to quickly launch a secure, customizable UI unified login form.
```
