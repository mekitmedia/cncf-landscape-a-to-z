## Overview

KusionStack is an intent-driven Platform Orchestrator that sits at the core of an Internal Developer Platform (IDP), enabling app-centric development through a single application specification.



## Key Features


- Provides an intent-driven Platform Orchestrator at the core of an Internal Developer Platform (IDP).

- Enables app-centric development via a single application specification, AppConfiguration.

- Abstracts underlying infrastructure tooling complexity with standardized, shared modules.

- Offers Kusion Server with a Developer Portal to centrally manage applications, instances, projects, and resources visually.

- Supports two key workflows: Day 0 for setting up modules and workspaces by platform engineers, and Day 1 for setting up the application by application developers.




## Use Cases

Simplifying application delivery by letting developers write a single specification, managing complex infrastructure via shared modules to enforce security and compliance, and providing a self-service deployment model for development teams.
