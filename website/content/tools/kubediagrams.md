## Overview

A tool to create Kubernetes architecture visualizations directly from manifests, kustomizations, Helm charts, and cluster states.



## Key Features


- most of all Kubernetes built-in resources

- any Kubernetes custom resources

- customizable resource clustering

- any Kubernetes resource relationships

- declarative custom diagrams

- an interactive diagram viewer

- a modern web application

- a plugin for JetBrains IDEs

- main input formats such as Kubernetes manifest files, customization files, Helm charts, helmfile descriptors, and actual cluster state

- main output formats such as D2, DOT, draw.io, GIF, JPEG, Mermaid, PDF, PNG, SVG, and TIFF




## Use Cases

Visualizing cloud-native applications, cluster state analysis, infrastructure documentation, Business Applications like Bank of Anthos, DeathStarBench, 5G Core Network Functions, Kubernetes Operators and Control Planes.
