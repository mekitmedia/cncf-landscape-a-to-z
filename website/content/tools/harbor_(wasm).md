## Overview

Harbor is an open source trusted cloud native registry project that stores, signs, and scans content, and includes support for managing WebAssembly (Wasm) artifacts.

## Key Features

- Cloud native registry with support for container images, Helm charts, and Wasm artifacts
- Role based access control through projects
- Policy based replication

## Use Cases

Container image registry, Helm chart registry, and Wasm artifact storage.
