## Overview

Ory Hydra provides a scalable OAuth 2.0 and OpenID Connect server designed for high throughput, low latency, and absolute control over UI flows via a custom login and consent app.



## Key Features


- OAuth 2.0 and OpenID Connect flows

- Token issuance and validation

- Client management

- Consent and login flow orchestration

- JWKS management

- Low latency and high throughput




## Use Cases

OAuth2 and OpenID Connect for single sign on, API access, and machine to machine authorization
