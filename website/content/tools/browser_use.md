## Overview

Browser Use is an open-source browser agent that enables AI models to navigate the web like a human does.



## Key Features


- Navigate the web like a human does.

- Run it locally with any LLM, or on Browser Use Cloud.

- Rerun a task without calling the model on every step.

- Use custom tools with the agent.




## Use Cases

Automate browser tasks, book appointments by navigating forms and handling CAPTCHAs, or control cloud browsers via the CLI or Python library.



{{< callout title="Getting Started" type="code" >}}
```bash
Install or upgrade browser-use to the latest stable version with uv using Python 3.12, run `browser-use skill install` to register the skill, and connect it to your browser.
```
{{< /callout >}}
