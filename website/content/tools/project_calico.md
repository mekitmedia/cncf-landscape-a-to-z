## Overview

Project Calico is an open-source solution for container networking and security, created and maintained by Tigera. It is widely adopted and powers over 8 million nodes daily.



## Key Features


- Data Plane Choice: Offers eBPF, standard Linux, Windows, and VPP.

- Interoperability: Works across multiple distros, clouds, bare metal, and VMs.

- Optimized Performance: High speed and low CPU usage.

- Advanced Security: Granular access controls and WireGuard encryption.

- Flexible networking: Includes BGP, VXLAN, and service advertisement.




## Use Cases

Container networking, network security, and advanced network policies for Kubernetes clusters across various environments.
