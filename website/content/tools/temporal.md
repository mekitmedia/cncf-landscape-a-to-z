## Overview

Temporal is a durable execution platform that helps developers build scalable applications with high productivity and reliability. It executes Workflows resiliently by handling intermittent failures and retrying operations automatically.



## Key Features


- Durable execution platform

- Executes Workflows in a resilient manner

- Automatically handles intermittent failures

- Retries failed operations

- Originated as a fork of Uber's Cadence




## Use Cases

Building scalable applications without sacrificing productivity or reliability.
