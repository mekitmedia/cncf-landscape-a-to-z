## Overview

Direktiv is a cloud-agnostic, serverless flow engine that capitalizes on microservices, containers and custom code to create efficient processes.



## Key Features


- Event-driven system and container approach for linking different systems.

- YAML-based flow description system to easily customize flows and expand capabilities.

- Acts as a broker for multiple backends with error handling, retries, logging and tracing capabilities.




## Use Cases

Useful for event-driven serverless orchestration, integration of multiple backends, and automation of repetitive tasks like continuous integration or infrastructure management.
