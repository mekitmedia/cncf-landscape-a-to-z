## Overview

Agno is a framework and runtime for agent platforms, allowing you to build, run, and manage agentic software at scale while maintaining control of your data, memory, and security posture.



## Key Features


- Production API with over 50 endpoints, SSE, and websockets.

- Built-in storage for sessions, memory, knowledge, and traces.

- More than 100 integrations including GitHub, Slack, and Postgres.

- Context providers to access live data and human approval mechanisms for tools.

- Observability tools such as OpenTelemetry tracing and audit logs.




## Use Cases

Building local or cloud-hosted agent platforms, orchestrating AI agent pipelines, running agent workloads with enterprise-grade RBAC, and interacting with agents via Slack, WhatsApp, or standard web UI.



{{< callout title="Getting Started" type="code" >}}
```bash
Clone the `agentos-railway` template or similar starters, and run it locally with Docker to get a REST API, Postgres DB, and MCP server out-of-the-box.
```
{{< /callout >}}



## Recent Updates

Agno continues to develop its robust ecosystem for agentic software with active development across SDKs, Docker images, and cloud deployments.



{{< callout title="Did You Know?" type="info" >}}
Agno supports deployment anywhere that runs containers, from local Docker to AWS, GCP, Azure, and Modal, while sending minimal telemetry (which can be disabled) to prioritize model provider integrations.
