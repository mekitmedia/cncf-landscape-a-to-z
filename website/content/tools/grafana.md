## Overview

An open-source observability and data visualization platform that allows users to monitor metrics, logs, and traces from a wide range of disparate data sources.



## Key Features


- Extensive visualization options using customizable client-side graphs and panel plugins

- Dynamic dashboards powered by template variables

- Interactive data exploration with ad-hoc querying and time range comparisons

- Seamless transition between metrics and logs while preserving label context

- Visual alerting engine with notifications for external systems like Slack and PagerDuty

- Ability to combine multiple different data sources within a single graph




## Use Cases

Visualizing logs, metrics, and traces, creating dynamic monitoring dashboards, analyzing telemetry data, and setting up alerting.
