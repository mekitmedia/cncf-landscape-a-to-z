## Overview

Open source platform for X.509 certificate based service authentication and fine grained access control in dynamic infrastructures.



## Key Features


- X.509 Certificate Based Authentication

- Fine-grained Authorization (RBAC with JWT)

- Decentralized Access Control

- Zero Trust capabilities (traffic encryption, AuthN, AuthZ)




## Use Cases

Service identity in the form of short-lived X.509 certificates to all workloads deployed in private or public clouds, Authorization and identity provider solution for Kubernetes clusters, Service to service authorization.
