## Overview

Aserto provides fine-grained, policy-based, real-time authorization for APIs and microservices. It is the maintainer of the Topaz open-source authorizer.



## Key Features


- Resource-level access controls for any application

- ~1ms authorizations

- Support for RBAC, ABAC, or ReBAC

- Complete set of SDKs for easy integration

- Central control plane for managing users, policies, and authorization data

- Based on the Topaz open-source authorizer and Open Policy Agent (OPA)




## Use Cases

Adding real-time, fine-grained authorization to APIs and microservices without building undifferentiated plumbing.
