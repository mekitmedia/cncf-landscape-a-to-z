## Overview

KServe is a standardized Distributed Generative and Predictive AI Inference Platform for scalable, multi-framework deployment on Kubernetes, unifying AI inference workloads.



## Key Features


- Provides high-performance serving with GPU support and optimized memory management for large models.

- Supports multiple frameworks including TensorFlow, PyTorch, scikit-learn, XGBoost, ONNX, and more.

- Features intelligent request routing between predictor, transformer, and explainer components.

- Offers request-based autoscaling capabilities optimized for generative workload patterns with scale-to-zero support.




## Use Cases

KServe is ideal for high-scale, high-density and frequently-changing model serving use cases on Kubernetes.
