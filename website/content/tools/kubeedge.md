## Overview

KubeEdge is a graduated CNCF project built upon Kubernetes that extends native containerized application orchestration and device management to hosts at the Edge. It consists of a cloud part and an edge part.



## Key Features


- Kubernetes-native support for managing edge applications and devices with fully compatible APIs.




## Use Cases

Deploying complicated machine learning, image recognition, and event processing applications to the Edge where data is produced, improving responsiveness and data privacy.
