## Overview

Vector serves as an efficient observability data pipeline acting as an agent and aggregator to help you manage your logs, metrics, and traces.



## Key Features


- Built in Rust, Vector's primary design goal is reliability

- End-to-end platform that deploys as an agent or aggregator

- Unified tool for logs, metrics, and traces




## Use Cases

Reduce observability costs, transition between vendors seamlessly, enrich data quality, and consolidate observability agents to improve performance.
