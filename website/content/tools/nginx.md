## Overview

NGINX is the world's most popular Web Server, high performance Load Balancer, Reverse Proxy, API Gateway and Content Cache.



## Key Features


- High performance Load Balancer

- Reverse Proxy and API Gateway

- Content Cache

- Configurable via text-based directives

- Extensible via dynamic and static modules

- Architected to scale using a master process and worker processes




## Use Cases

Web Server, Load Balancer, Reverse Proxy, API Gateway, Content Cache

{{< callout title="Did You Know?" type="info" >}}
NGINX scales beyond Operating System process limitations by operating as a collection of processes. A master process maintains worker processes which automatically adjust to the number of available CPU cores.
