## Overview

Weights & Biases (W&B) allows you to build better models faster. It helps track and visualize all the pieces of your machine learning pipeline, from datasets to production machine learning models.

## Key Features

- Track and visualize machine learning pipelines, from datasets to production models
- Track, debug, evaluate, and monitor LLM apps with Weave
- Integrates with popular ML frameworks and libraries making it fast and easy to set up experiment tracking and data versioning
- Provides hosting options including Multi-tenant Cloud, Dedicated Cloud, and Self-Managed deployments

## Use Cases

Experiment tracking and data versioning for machine learning models, as well as tracking, debugging, evaluating, and monitoring LLM apps.
