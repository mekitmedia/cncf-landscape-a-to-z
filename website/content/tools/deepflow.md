## Overview

DeepFlow provides deep observability for complex cloud-native and AI applications, implementing Zero Code data collection with eBPF for metrics, distributed tracing, request logs, and function profiling.



## Key Features


- Universal Map for Any Service: Provides a universal map with Zero Code by eBPF for production environments.

- Distributed Tracing for Any Request: Zero Code distributed tracing powered by eBPF supports applications in any language and infrastructures.

- Continuous Profiling for Any Function: Collects profiling data at a cost of below 1% with Zero Code.

- Seamless Integration with Popular Stack: Can serve as storage backend for Prometheus, OpenTelemetry, SkyWalking and Pyroscope.

- Performance 10x ClickHouse: SmartEncoding injects standardized and pre-encoded meta tags into all observability data.
