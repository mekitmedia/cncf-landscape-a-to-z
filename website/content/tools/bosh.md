## Overview

An open source release engineering, deployment, and lifecycle management tool for distributed systems.



## Key Features


- Unifies release engineering, deployment, and lifecycle management of small and large-scale cloud software.

- Performs monitoring, failure recovery, and software updates with zero-to-minimal downtime.

- Supports multiple Infrastructure as a Service (IaaS) providers like VMware vSphere, Google Cloud Platform, Amazon Web Services EC2, Microsoft Azure, OpenStack, and Alibaba Cloud.




## Use Cases

Provision and deploy software over hundreds of VMs, particularly well-suited for large distributed systems like Cloud Foundry PaaS or Hadoop.
