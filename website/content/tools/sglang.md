## Overview

SGLang provides a high-performance open-source inference framework designed for large language, vision-language, and diffusion models, specifically optimized for large-scale serving, agentic workloads, and RL rollouts.

## Key Features

- Inference framework for large language, vision-language, and diffusion models
- Optimized for agentic workloads, large-scale serving, and RL rollouts
- Built-in image and video generation engine (SGLang Diffusion)
- Supports a wide range of hardware platforms including GPUs, TPUs, NPUs, CPUs, and Apple Silicon

## Use Cases

Serving production workloads across AI labs, cloud platforms, enterprises, and universities.
