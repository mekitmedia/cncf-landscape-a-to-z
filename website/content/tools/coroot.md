## Overview

An open-source observability and APM tool with AI-powered Root Cause Analysis. It brings together metrics, logs, traces, continuous profiling, and SLO-based alerting into a unified platform.



## Key Features


- Zero-instrumentation observability automatically gathered by using eBPF.

- Service Map that covers 100% of your system with no blind spots.

- Predefined inspections audit each application without any configuration.

- Application Health Summary for tracking service status, logs, and SLOs (Service Level Objectives).

- Distributed tracing with Vendor-neutral instrumentation via OpenTelemetry.

- Logs-to-traces correlation and event clustering backed by ClickHouse.

- One-click continuous profiling down to the precise line of code.

- Built-in expertise automatically identifies over 80% of issues and aggregates alerts.

- Deployment tracking of Kubernetes rollouts without requiring CI/CD integration.

- Cost Monitoring for AWS, GCP, Azure down to the specific application.




## Use Cases

Zero-instrumentation observability with eBPF, continuous profiling, and AI-powered Root Cause Analysis for Kubernetes and containerized applications.
